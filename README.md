# グラブル天井計算

グランブルーファンタジーのガチャの**天井（300連）**までの残りを計算する、ブラウザだけで動くツールです。
サーバーやインストールは不要で、ブラウザで開くだけで使えます。

## 機能
- 宝晶石、単発・10連チケット、モバコイン、蒼光の輝きから、今何連分あるかを計算する
- 天井何回分か、次の天井まであと何連・宝晶石何個・モバコイン何枚（約何円）かを出す
- ガチャチケットを宝晶石に換算した数も出す

## 使い方
https://syugo1142.github.io/gbf-tenjou-keisan/ を開くだけで使えます。

手元で使う場合は、このリポジトリをダウンロードして（Code → Download ZIP、または `git clone`）、`index.html` をブラウザで開いてください。

入力した数はブラウザのlocalStorageに保存され、サーバーには送られません。

宝晶石300個＝1連、モバコイン300枚＝1連（1枚＝宝晶石1個、100枚＝105円）、10連チケット＝10連として計算しています。
