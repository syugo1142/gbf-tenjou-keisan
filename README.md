# グラブル天井計算

グランブルーファンタジーのガチャの天井（300連）までの残りを計算するツールです。ブラウザで開いて使います。

## 機能
- 宝晶石、単発チケット、10連チケット、モバコイン、蒼光の輝きから、今何連分あるかを計算する
- 天井何回分か、次の天井まであと何連・宝晶石何個・モバコイン何枚（約何円）かを表示する
- チケットを宝晶石に換算した数を表示する

宝晶石300個＝1連、モバコイン300枚＝1連（1枚＝宝晶石1個、100枚＝105円）、10連チケット＝10連として計算します。

## 使い方
https://syugo1142.github.io/gbf-tenjou-keisan/ を開きます。

手元で使う場合は、このリポジトリをダウンロードして（Code → Download ZIP、または `git clone`）、`index.html` をブラウザで開きます。

入力した数はブラウザのlocalStorageに保存し、サーバーには送りません。

## ファイル構成
```
index.html
style.css
spark.js   # 計算と表示、保存
```
